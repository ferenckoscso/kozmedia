# A jövő közmédiája

Interaktív bemutató a "Manifesztum a jövőálló közmédiáról" (Koscsó Ferenc / Koscso Media Engineering Kft.) alapján.

Élő oldal: https://ferenckoscso.github.io/kozmedia/

## Fejlesztés

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

A `main` branch-re pusholt commitok automatikusan deployolódnak GitHub Pages-re (`.github/workflows/deploy.yml`).

## Stack

React 19 + TypeScript + Vite, Tailwind CSS, shadcn/ui (Radix primitívek), GSAP.
